レシピ抜き出しの設定

Safariで見ているレシピを、共有ボタンから抜き出してコピーできるようにします。最初に1回だけ、iPhoneのショートカットを作ります。

1. スクリプトを許可する

iPhoneの設定 → アプリ → ショートカット → 詳細 と進み、スクリプトの実行を許可をオンにします。

iOSが古いときは、設定 → ショートカット → 詳細 です。

2. 中身をコピーする

3. ショートカットを作る

  1. ショートカットアプリを開き、右上の＋を押す
  2. 検索欄に JavaScript と入れて、WebページでJavaScriptを実行を選ぶ
  3. 入っている例の文字を全部消して、長押しでペーストする（2. でコピーした中身）
  4. 検索欄に クリップボード と入れて、クリップボードにコピーを選ぶ（中身は前の動作の結果のまま）
  5. 上の名前をレシピ抜き出しにする
  6. 名前の横のメニューかⓘから共有シートに表示をオンにして、受け取るものをSafari Webページだけにする
  7. 完了を押す

iOSのバージョンによって、ボタンの名前や場所が少し違うことがあります。

4. 使い方

  1. Safariでレシピのページを開き、共有ボタン → レシピ抜き出しを押す
  2. 初めてのサイトでは許可を聞かれるので、許可を押す
  3. ページの上に内容が出て、全部がコピーされます。材料だけ欲しいときは、そこで材料だけを押す
  4. ホーム画面のレシピアプリで＋追加 → コピーした文字を読み込む → 保存
共有シートに出ないときは、一覧のいちばん下のアクションを編集から追加できます。
